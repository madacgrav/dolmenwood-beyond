# Task

Extend the campaign calendar so players can mark their own free/busy availability against proposed campaign dates, rather than only RSVPing yes/no/maybe to fixed sessions already created by the referee. When every member of a campaign marks a given date as available (approves it), the system should send an email confirming the agreed-upon date to the group.

This builds on the existing Schedule tab (`campaign_sessions` + `session_rsvps`) and requires a new email/notification capability the app does not currently have.
