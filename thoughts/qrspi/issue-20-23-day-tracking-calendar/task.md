# Task

Two related V2-backlog features (GitHub issues #20 and #23), grouped because both hang off an in-game notion of "a day passing":

- **#20 — Track day / skill reset automation:** automate per-day ability resets and downtime tracking, so advancing an in-game day refreshes resettable resources (spell slots, use-limited abilities, etc.) instead of the player resetting each by hand.
- **#23 — Dolmenwood calendar / moon-phase tracker:** an in-world Dolmenwood calendar with moon-phase tracking (distinct from the real-world player availability calendar already being designed separately).

Both are excluded from V1.0 (PRD `docs/prd.md` §10). The link is a shared concept of in-world time/current day; research should reveal whether one time model can drive both.
