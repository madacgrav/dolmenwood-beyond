# Task

Audit the character sheet UI against the official Dolmenwood printed character
sheet PDF (`Dolmenwood Character Sheet 2025-02-07.pdf`). Enumerate every field,
stat, and section the printed sheet shows, map each to the app's character sheet
UI, and identify what is missing, extra, renamed, or organized differently — so
we can decide what (if anything) to add or align.

## Reference: what the printed PDF shows

**Front (page 1):**
- Identity: Name, Kindred & Class, Background, Alignment, Affiliation, Moon Sign, portrait box
- Ability Scores ×6 (Strength, Intelligence, Wisdom, Dexterity, Constitution, Charisma), each SCORE + MOD
- Save Targets: Doom, Ray, Hold, Blast, Spell, Magic Resistance
- HP / Max HP, AC, Attack
- Movement: Speed (Feet/Round), Exploring (Feet/Turn), Overland (Travel Points/day)
- Kindred & Class Traits (freeform box)
- Skill Targets: Listen, Search, Survival, + Modifier
- Languages
- XP, Level, Next Level, Modifier

**Back (page 2):**
- Encumbrance Method: Weight vs Slots
- Item categories: Tiny Items, Stowed Items, Equipped Items (with weights)
- Weight/Speed track (40/30/20/10)
- Total Weight
- Other Notes
- Coins: Copper, Silver, Gold, Pellucidium
